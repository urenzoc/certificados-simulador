1. Conceptos y funcionalidades de IA

40–45% del examen

IA responsable, cómo funcionan los modelos generativos y las cargas de trabajo de IA.

Principios de IA responsable de Microsoft

PrincipioPregunta que respondeEjemplo
Equidad¿Trata a todos por igual?Un modelo de crédito no debe discriminar por género o etnia
Confiabilidad y seguridad¿Funciona bien y sin causar daño en condiciones reales?Probar un sistema médico en casos límite
Privacidad y seguridad¿Protege los datos personales?Anonimizar datos de entrenamiento

Cómo funcionan los modelos generativos

  • Un modelo de lenguaje grande (LLM) se entrena con enormes cantidades de texto y predice el siguiente token (fragmento de palabra) según el contexto. La arquitectura base es el transformer con mecanismo de atención.
  • Embeddings: vectores numéricos que representan significado; textos parecidos quedan cerca. Base de la búsqueda semántica y RAG.
  • Ventana de contexto: cuántos tokens caben entre entrada y salida.
  • Alucinación: respuesta convincente pero falsa. Se mitiga con grounding/RAG (dar documentos fuente) y buenos prompts.
  • Modelos multimodales: aceptan texto, imagen y/o audio (por ejemplo GPT-4o / GPT-4.1).
  • Modelos de lenguaje pequeños (SLM), como Phi: más baratos y rápidos, para tareas acotadas o dispositivos.

Elegir y desplegar modelos

ParámetroEfecto
TemperaturaAleatoriedad: baja = respuestas deterministas; alta = creativas
Top_pMuestreo por probabilidad acumulada; alternativa a temperatura (ajusta uno de los dos)
Máximo de tokensLímite de longitud de la respuesta
Penalización de frecuencia/presenciaReduce repeticiones / favorece temas nuevos
Secuencias de detenciónCortan la generación al aparecer un texto
  • El catálogo de modelos de Foundry tiene modelos de OpenAI, Microsoft (Phi), Meta (Llama), Mistral, DeepSeek y otros; se comparan con tablas de clasificación (calidad, costo, rendimiento).
  • Tipos de despliegue: Estándar (pago por token), Global (máxima disponibilidad), Zona de datos (procesamiento dentro de EE. UU./UE), Aprovisionado (capacidad reservada, latencia predecible), Batch (asíncrono, más barato).
  • Para invocar un modelo se usa el nombre del despliegue, no solo el nombre del modelo.

  • Reconocimiento de voz (speech to text): transcripción en tiempo real o por lotes; modelos personalizados para vocabulario especial.
  • Síntesis de voz (text to speech): voces neuronales; SSML controla pronunciación, pausas, velocidad y tono.
  • Traducción de voz: habla de un idioma a texto/voz en otro.
  • Visión: descripción/subtítulos, etiquetado, detección de objetos (con cuadro delimitador), OCR (leer texto), y generación de imágenes (GPT-image, DALL-E, FLUX).

Trampas frecuentes

  • Clasificación de imágenes (una etiqueta para toda la imagen) ≠ detección de objetos (ubica cada objeto con coordenadas).
  • OCR lee texto; no entiende el formulario. Para campos estructurados usa Content Understanding/Document Intelligence.
  • Transparencia ≠ responsabilidad: explicar vs. quién responde.

2. Implementar soluciones de IA con Microsoft Foundry

55–60% del examen

Prompts, despliegues, SDK, agentes, voz, visión y extracción de información.

Recursos de Foundry

  • Un recurso de Foundry agrupa modelos, herramientas (Foundry Tools: Language, Speech, Vision, Content Understanding…) y seguridad. Dentro hay proyectos, que son el espacio de trabajo de cada equipo.
  • El punto de conexión del proyecto se usa desde el SDK. Autenticación recomendada: Microsoft Entra ID (DefaultAzureCredential) en lugar de claves.
  • El playground del portal permite probar prompts, parámetros y agentes antes de programar.

Prompts efectivos

ElementoPara qué
Mensaje del sistemaDefine rol, tono, alcance, reglas y formato de salida
Mensaje del usuarioLa petición concreta
Few-shot (ejemplos)Pares entrada/salida para enseñar el formato esperado
Contexto / groundingDatos o documentos en los que basar la respuesta
Instrucciones clarasDelimitadores, pasos ordenados, longitud y formato (JSON, lista)

Aplicaciones de chat con el SDK

  • Flujo típico: crear el cliente con el punto de conexión del proyecto y credencial → obtener un cliente compatible con OpenAI → enviar mensajes (system + user) al despliegue → leer la respuesta.
  • Para conversación con memoria hay que reenviar el historial o encadenar con el identificador de la respuesta anterior (Responses API).
from azure.identity import DefaultAzureCredential
from azure.ai.projects import AIProjectClient

project = AIProjectClient(endpoint=PROJECT_ENDPOINT, credential=DefaultAzureCredential())
client = project.get_openai_client()
resp = client.responses.create(model="mi-despliegue", input="Resume este texto…")
print(resp.output_text)

Agentes

  • Un agente combina modelo + instrucciones + herramientas (búsqueda en archivos, Code Interpreter, búsqueda web/Bing, funciones, OpenAPI, MCP, Azure AI Search).
  • Se crea y prueba en el portal (Foundry Agent Service) y luego se usa desde una app cliente con conversaciones/hilos.
  • File Search responde con tus documentos; Code Interpreter ejecuta Python para cálculos y gráficos.

Texto y voz en Foundry

  • Azure Language: análisis de sentimiento, entidades, frases clave, PII, resumen, detección de idioma, respuesta a preguntas.
  • Un modelo multimodal con entrada de audio puede responder a prompts hablados directamente.
  • Azure Speech: SpeechRecognizer (voz a texto), SpeechSynthesizer (texto a voz), traducción de voz; Voice Live para agentes de voz en tiempo real.

Visión y generación de imágenes

  • Interpretar imágenes: enviar en el mismo mensaje texto + imagen (URL o base64) a un modelo multimodal.
  • Generar imágenes: modelos GPT-image (generación y edición con máscara), FLUX, etc. Video: Sora.
  • Azure Vision: subtítulos, etiquetas, objetos, OCR (Read), recorte inteligente.

Extracción de información con Content Understanding

EntradaQué extrae
Documentos y formulariosTexto, tablas, estructura (Markdown) y campos definidos en un esquema
ImágenesDescripciones y campos personalizados
AudioTranscripción, resumen, campos (p. ej. motivo de la llamada)
VideoSegmentos, escenas, transcripción y campos por segmento
  • Un analizador define el esquema de campos a extraer; hay analizadores precompilados (factura, recibo…) y personalizados.
  • Campos extraídos (literalmente presentes) vs. generados (inferidos por el modelo) vs. clasificados (una categoría de una lista).
  • Los resultados incluyen confianza y grounding (ubicación de la fuente).

Trampas frecuentes

  • Modelo (catálogo) ≠ despliegue (instancia invocable con nombre propio).
  • Temperatura y top_p: cambia uno, no ambos.
  • Content Understanding sirve para documentos, imágenes, audio y video; Document Intelligence se centra en documentos.
Glosario rápido (122 términos)
Accountability
Personas responsables del diseño, despliegue y operación: dueños designados, gobernanza, auditoría y revisión humana.
agent_reference
En responses.create(), extra_body={"agent_reference": {"name": ..., "type": "agent_reference"}} indica qué agente de Foundry atiende la solicitud.
Agents playground
Espacio del portal para configurar instrucciones y herramientas de un agente y probar conversaciones multiturno sin código.
AIProjectClient
Cliente del Foundry SDK (azure-ai-projects): se conecta al endpoint del proyecto; gestiona agentes y devuelve el cliente compatible con OpenAI.
Alucinación
El modelo genera contenido convincente pero falso. Se mitiga con grounding/RAG, buenos datos fuente e instrucciones de responder solo con las fuentes.
Analizador personalizado
Parte de un analizador base (prebuilt-document, prebuilt-image, prebuilt-audio, prebuilt-video) y define un field_schema. Se crea con begin_create_analyzer. Para producción estable, crea tu propio analizador en vez de depender del prebuilt.
Analizadores prebuilt de búsqueda
prebuilt-documentSearch, prebuilt-imageSearch (descripción de imagen), prebuilt-audioSearch (transcripción, resumen, hablantes) y prebuilt-videoSearch (keyframes, transcripción, capítulos).
Analizadores prebuilt de dominio
Extraen campos de documentos de negocio: prebuilt-invoice (facturas), prebuilt-receipt (recibos), prebuilt-idDocument, prebuilt-contract y prebuilt-procurement (órdenes de compra, facturas y otros documentos de compras).
Análisis de sentimiento
Etiqueta el texto como positive, neutral, negative o mixed con puntuaciones de confianza. Método: analyze_sentiment().
Análisis de sentimiento (carga de trabajo)
Determina si un texto expresa una opinión positiva, negativa o neutral. Es parte del NLP.
API key
Clave del recurso. Se envía con el endpoint; guárdala en variables de entorno o Key Vault, nunca en el código. Los recursos traen dos claves para poder rotarlas sin cortar el servicio.
Aprendizaje por refuerzo
Un agente aprende por prueba y error recibiendo recompensas o penalizaciones (robótica, juegos).
Audio en modelos de chat
input_audio envía audio codificado en línea; audio_url hace referencia a audio en la nube. modalities=["text","audio"] con audio={...} pide respuesta hablada. Se prueba en el Audio playground.
Azure Face
Detección (localiza rostros y atributos), verificación 1:1, identificación 1:N en un grupo registrado, agrupación y liveness (real vs. foto o máscara). Identificación y verificación son de acceso limitado.
Azure Language
Servicio de NLP: sentimiento, frases clave, entidades, PII, idioma, resumen y clasificación. En Python: azure-ai-textanalytics con TextAnalyticsClient(endpoint, AzureKeyCredential(key)).
Azure Speech
Speech to text, text to speech, traducción de voz, identificación de idioma, diarización y Voice Live.
Azure Translator
Traduce texto entre más de 100 idiomas (códigos ISO 639-1) y documentos: síncrono (uno, directo) o asíncrono por lotes con Azure Blob Storage, conservando el formato. Custom Translator adapta terminología.
Azure Vision
Image Analysis: CAPTION, DENSE_CAPTIONS, TAGS, OBJECTS, PEOPLE, READ (OCR) y SMART_CROPS. Paquete azure-ai-vision-imageanalysis; método analyze() o analyze_from_url() (URL pública).
begin_analyze / poller
client.begin_analyze(analyzer_id=..., inputs=[AnalysisInput(url=...)]) inicia un análisis asíncrono; poller.result() espera y devuelve el resultado.
Búsqueda semántica
Busca por significado e intención, no solo por palabras exactas, y devuelve resultados relevantes según el contexto (embeddings y re-ranking semántico en Azure AI Search).
Captions
Captioning describe la imagen completa en una oración; dense captions describe varias regiones con su bounding box.
Chat completions
API de chat con una lista de messages (system, user, assistant). Con azure-ai-inference se usa ChatCompletionsClient.complete().
Clasificación
Aprendizaje supervisado que predice una categoría: binaria (spam/no spam, fraude/no fraude) o multiclase (bajo/medio/alto).
Clasificación de imágenes
Asigna una o varias etiquetas a la imagen completa, sin ubicar los objetos.
Clustering
Aprendizaje no supervisado que agrupa elementos similares sin etiquetas previas (segmentación de clientes).
CNN
Redes neuronales convolucionales: aprenden filtros que detectan patrones espaciales (bordes, formas); ideales para imágenes.
Compare models
Función del playground para enviar el mismo prompt a varios modelos y comparar respuestas lado a lado.
Content Safety
Detecta contenido dañino con niveles de severidad; los filtros de contenido de Foundry bloquean entradas y salidas según umbrales.
Content Understanding
Usa IA generativa para extraer información estructurada de documentos, imágenes, audio y video según un esquema; devuelve markdown, campos JSON y confianza.
Conversations
openai.conversations.create() crea una conversación que conserva el historial entre turnos; se pasa en responses.create(conversation=...).
Convolución y kernels
Un kernel se desliza sobre la imagen y calcula sumas ponderadas locales: detección de bordes (resalta cambios de intensidad), desenfoque (suaviza ruido) o nitidez.
Deep learning
Redes neuronales de muchas capas que aprenden representaciones jerárquicas; requieren más datos y cómputo y son menos interpretables.
DefaultAzureCredential
Autenticación con Microsoft Entra ID sin claves en el código (usa az login, managed identity, etc.). Scope de token para Foundry: https://ai.azure.com/.default.
Deployment
Un modelo debe desplegarse para usarse en inferencia. El parámetro model del código lleva el nombre del deployment (por defecto, el nombre del modelo).
Detección de anomalías
Identifica valores o comportamientos inusuales en datos (p. ej., lecturas de sensores o transacciones atípicas). No analiza imágenes ni conversaciones.
Detección de idioma
Devuelve el idioma de un texto con nombre, código ISO 639-1 y confianza de 0 a 1. Método: detect_language().
Detección de objetos
Identifica varios objetos con etiqueta, confianza y coordenadas de bounding box.
Diarización
Identifica qué hablante dijo cada segmento de una transcripción.
División de datos
Separar datos de entrenamiento y validación/prueba (al azar, más para entrenamiento, p. ej., 70/30). La validación cruzada rota los subconjuntos para medir mejor.
Document Intelligence
Extrae texto (OCR), pares clave-valor, tablas y estructura de documentos con modelos prebuilt o personalizados entrenados con ejemplos etiquetados.
Early stopping
Detiene el entrenamiento cuando el desempeño en validación empieza a empeorar.
Embeddings
Vectores numéricos que representan el significado: textos parecidos quedan cerca. Se usan en búsqueda semántica y RAG (text-embedding-3-large).
Endpoint
URL del recurso o proyecto. Proyecto: https://<recurso>.services.ai.azure.com/api/projects/<proyecto>. OpenAI v1: https://<recurso>.openai.azure.com/openai/v1/. Servicios: https://<recurso>.cognitiveservices.azure.com/.
Evaluación
Las evaluaciones de Foundry miden la calidad (relevancia, coherencia, groundedness) y la seguridad de las respuestas antes de liberar una app.
Fairness (equidad)
Tratar de forma justa a todas las personas; comparar resultados entre grupos y usar datos representativos.
Features y labels
Features: variables de entrada. Label: valor que se quiere predecir (solo en aprendizaje supervisado).
Few-shot
Incluir ejemplos de entradas y respuestas esperadas (mensajes user/assistant) para orientar el formato y el comportamiento del modelo.
Fine-tuning
Ajustar los pesos de un modelo base con ejemplos de tu tarea para que siga un estilo o formato de forma consistente. Un modelo base es uno sin personalizar.
Foundry Agent Service
Servicio que hospeda agentes: modelo + instrucciones + herramientas, con el runtime y el historial de conversación administrados.
Foundry Tools
Servicios de IA listos para usar dentro de Foundry: Speech, Language, Translator, Vision, Content Understanding, Content Safety y Document Intelligence.
Frases clave
Devuelve los temas o conceptos principales como una lista corta. Método: extract_key_phrases().
get_openai_client()
Método de AIProjectClient que devuelve un cliente compatible con OpenAI para Responses, Conversations y chat completions.
GPT-Image
Modelos que generan o editan imágenes a partir de texto. GPT-Image es la familia recomendada; admite inpainting, fondo transparente (PNG) y partial_images con streaming. La respuesta trae la imagen en b64_json.
Herramientas de agentes
Web search (información pública actual con citas), File Search (tus documentos), Code Interpreter (ejecuta Python), function calling y MCP (APIs y herramientas externas).
Hosted agent
Agente con tu propio código empaquetado en un contenedor y hospedado por Foundry.
IA agéntica
Sistemas que completan objetivos de forma autónoma: planifican, usan herramientas y ejecutan varios pasos.
IA conversacional
Interacción en lenguaje natural por texto o voz: chatbots y asistentes virtuales.
IA generativa
Crea contenido nuevo (texto, imágenes, audio, código) a partir de prompts, prediciendo un token a la vez.
Imagen como entrada
La imagen se envía como URL pública o como data URL en base64 (data:image/png;base64,...), junto con un elemento de texto en el mismo mensaje del usuario.
Imagen digital
Cuadrícula de píxeles; a color = tres matrices (R, G, B) con valores de 0 a 255. La escala de grises usa una sola, pero pierde información de color.
Inclusiveness
Que la mayor cantidad de personas pueda usar la IA: varios modos de interacción, subtítulos, lectores de pantalla, idiomas y acentos.
Ingeniería de prompts
Diseñar prompts con instrucciones claras, contexto, datos de entrada e indicadores de salida (formato, longitud) para mejorar la calidad de las respuestas.
Intent y entidades
El intent es el propósito del mensaje; las entidades son los datos clave (fechas, ciudades). Se entrena con utterances etiquetadas.
Interpretabilidad vs. desempeño
Modelos simples (árboles) se explican fácil; modelos complejos pueden ser más precisos pero opacos. SHAP/LIME ayudan a explicarlos.
Knowledge mining
Ingerir → enriquecer con habilidades de IA (OCR, entidades, traducción) → indexar en Azure AI Search para hacer buscable el contenido.
Knowledge vs. Tools
Knowledge aporta datos para fundamentar respuestas (p. ej., documentos internos, Foundry IQ); Tools ejecutan acciones o búsquedas externas (p. ej., búsqueda web).
Machine learning
Algoritmo = procedimiento que aprende patrones de los datos; modelo = resultado entrenado que hace predicciones.
max tokens
Límite superior de tokens que puede generar la respuesta (en modelos de razonamiento incluye los tokens de razonamiento).
Microsoft Foundry
Plataforma unificada de IA de Microsoft para crear apps y agentes: modelos, playgrounds, agentes, herramientas, evaluación y monitoreo.
Model catalog
Catálogo de modelos de Foundry (Microsoft, OpenAI, Meta, Mistral, Hugging Face...) para explorar, comparar por capacidades y desplegar.
Modelo de razonamiento
Modelos que razonan en varios pasos antes de responder y planifican el uso de herramientas; útiles para tareas complejas.
Modelo multimodal
Acepta varias entradas (texto, imagen, audio) en el mismo mensaje. Puede describir imágenes y responder preguntas sobre ellas.
Modelos pequeños (SLM)
Modelos de lenguaje pequeños como Phi: rápidos, baratos y aptos para entornos con poco cómputo.
Métodos de campo
extract: valor que aparece literalmente; generate: el modelo lo produce (p. ej., un resumen); classify: elige entre los valores de un enum.
Métricas
Silhouette cerca de 1 = clusters bien separados. Bajar el umbral de un clasificador aumenta verdaderos y falsos positivos.
Negative prompting
Indicar explícitamente lo que el modelo debe evitar (p. ej., afirmaciones exageradas).
OCR
Extrae texto impreso y manuscrito de imágenes y documentos, con su ubicación. El preprocesamiento (contraste, nitidez, iluminación) mejora la precisión.
Opciones del analizador
enableOcr para escaneos y PDFs de imágenes; estimateFieldSourceAndConfidence devuelve página, bounding box y confianza; enableSegment divide video en escenas. La confianza indica qué tan confiable es un valor extraído.
Overfitting
El modelo memoriza el ruido: muy buen desempeño en entrenamiento y malo con datos nuevos (alta varianza). Se corrige con más datos, regularización, early stopping o modelos más simples.
Paquete del Speech SDK
Speech SDK para Python: pip install azure-cognitiveservices-speech.
Penalties y stop
frequency_penalty y presence_penalty reducen repeticiones; las stop sequences cortan la salida al aparecer cierto texto.
PII
Detecta información personal (nombres, teléfonos, correos, IDs), la categoriza con confianza y devuelve el texto ocultado. Método: recognize_pii_entities().
Playground
Interfaz del portal para probar prompts y modelos sin código: Chat, Agents, Images, Video, Audio y Speech playgrounds. La pestaña Code muestra el código equivalente.
prebuilt-documentFields / FieldSchema
prebuilt-documentFields extrae pares clave-valor sin esquema de dominio; prebuilt-documentFieldSchema propone un esquema de campos para un tipo de documento nuevo.
Privacidad de datos en Azure
Tus prompts y respuestas no están disponibles para otros clientes ni se usan para entrenar o mejorar modelos sin tu permiso.
Privacy and Security
Proteger datos y sistemas: minimizar datos, cifrado, RBAC, mínimo privilegio, identidades administradas y PII.
Procesamiento de lenguaje natural (NLP)
Carga de trabajo que analiza y entiende texto: sentimiento, frases clave, entidades, idioma, resumen, traducción. No analiza imágenes ni video.
Prompt agent
Agente único definido de forma declarativa (modelo, instrucciones, herramientas). Se crea y prueba en el portal sin código; en código, con PromptAgentDefinition.
RAG
Retrieval Augmented Generation: recupera información relevante de una fuente externa y la agrega al prompt para fundamentar la respuesta. Reduce alucinaciones sin reentrenar.
Reconocimiento de entidades (NER)
Identifica y categoriza personas, organizaciones, ubicaciones, fechas, productos... Método: recognize_entities().
Recurso multiservicio
Un recurso multiservicio da acceso a varios servicios de IA con un solo endpoint, una sola clave y facturación unificada. Los de servicio único sirven para aislar o controlar costos por servicio.
Regresión
Aprendizaje supervisado que predice un valor numérico continuo (precio, tarifa, demanda, retraso en minutos).
Regularización
Penaliza parámetros extremos o modelos demasiado complejos para reducir el overfitting.
Reliability and Safety
Funcionar de forma consistente y segura, incluso ante entradas inesperadas; pruebas, umbrales, fallback, revisión humana y monitoreo.
Responses API
API para generar respuestas: responses.create(model=<deployment>, input=<prompt>). previous_response_id continúa una respuesta anterior; output_text trae el texto.
Resumen
Produce una versión más corta de un texto o conversación (extractivo o abstractivo). No asigna sentimiento ni extrae entidades.
Segmentación semántica
Clasifica cada píxel según el objeto al que pertenece, para obtener contornos precisos.
Seguridad de red
Private endpoints y redes virtuales reducen la exposición del recurso a internet pública.
Sora
Genera video MP4 a partir de un prompt de texto (opcionalmente imágenes), con size (resolución) y seconds (duración), mediante un trabajo asíncrono. Sora 2 puede generar audio sincronizado.
Speech to text
Convierte audio hablado en texto: en tiempo real (micrófono, subtítulos en vivo), transcripción rápida (archivos, síncrona) o por lotes (grandes volúmenes guardados, asíncrona).
SpeechConfig / AudioConfig
SpeechConfig: clave/endpoint/región, idioma y voz. AudioConfig: micrófono o archivo de entrada (o salida a archivo con filename).
SpeechRecognizer / SpeechSynthesizer
SpeechRecognizer convierte voz en texto (recognize_once_async para una frase; start_continuous_recognition_async para audio largo). SpeechSynthesizer convierte texto en voz (speak_text_async, speak_ssml_async).
SSML
Speech Synthesis Markup Language: marcado para controlar pronunciación, tono, velocidad, pausas y estilo de la voz sintetizada.
System message
Define rol, tono, límites, reglas y formato de salida para toda la conversación.
Temperature
Controla la aleatoriedad: valores bajos dan respuestas más enfocadas y consistentes; valores altos, más variadas y creativas.
Text to speech
Convierte texto en voz natural con voces neuronales; SSML ajusta pronunciación, tono y velocidad.
Tipos de deployment
Standard (Global, Data Zone o regional; pago por token), Provisioned (capacidad reservada), Batch (asíncrono, más barato), serverless API (pago por uso) y managed compute (VM dedicada con cuota). Data Zone mantiene los datos en la UE o EE. UU.
Token
Unidad básica de texto que procesa un modelo (palabra, parte de palabra o carácter). El modelo genera la respuesta prediciendo un token a la vez.
tool_choice
Controla el uso de herramientas: auto (el modelo decide), required (debe llamar a una) o una herramienta específica.
top_p
Muestreo de núcleo: el modelo elige solo entre los tokens que suman cierta probabilidad. Normalmente se ajusta temperature o top_p, no ambos.
Tracing
El tracing registra las llamadas al modelo, las herramientas invocadas y el grounding de cada respuesta para depurar agentes.
Traducción de voz
Traduce lo hablado a otro idioma (texto o voz). En el SDK: SpeechTranslationConfig y add_target_language.
transcriptPhrases
En audio/video, transcriptPhrases trae frases con hablante y tiempos; el objeto contents usa kind audioVisual. El análisis de video incluye keyframes y segmentos.
Transformer
Arquitectura base de los LLM: usa mecanismos de atención para relacionar todas las partes de la entrada.
Transparency
Que las personas entiendan cómo funciona el sistema, sus capacidades y limitaciones, y sepan que interactúan con IA (Transparency Notes).
Underfitting
El modelo es demasiado simple y rinde mal en entrenamiento y en datos nuevos (alto sesgo).
User prompt
La solicitud concreta del usuario en cada turno.
Ventana de contexto
Cantidad máxima de tokens (entrada + historial) que el modelo puede considerar.
Visión por computadora
Carga de trabajo que interpreta imágenes y video: clasificar, detectar objetos (con su ubicación), leer texto (OCR), describir imágenes y analizar rostros.
Voice Live API
Integra reconocimiento de voz, modelo generativo y texto a voz en una sola interfaz de baja latencia para agentes de voz.
Whisper / transcripción
Whisper y gpt-4o-transcribe convierten audio hablado en texto (transcripción).
Workflow agent
Agente que orquesta varios pasos o agentes en un flujo.
